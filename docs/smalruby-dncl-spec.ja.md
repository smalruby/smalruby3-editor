# Smalruby 日本語モード言語仕様（共通テスト用プログラム表記）

このドキュメントは、smalruby3-editor の **日本語モード**（日本語タブ。コードでは「DNCL モード」と呼んでいる）で対応している構文と機能を定義します。
ソースコードの `packages/ja-notation/`（日本語 ⇔ Ruby の変換）、`packages/scratch-gui/src/lib/dncl/`（エディタとの橋渡し）と `packages/scratch-gui/src/containers/ruby-tab/dncl-mode.js`（Monaco エディタ言語定義）に基づいています。

> **注意**: 本ドキュメントは **smalruby3-editor における実装**を正として記載しています。共通テスト用プログラム表記にはまとまった仕様書が無く、問題文の補足で読めるようにした書き方です。スモウルビーで決めたところは [共通テスト用プログラム表記との違い](#11-共通テスト用プログラム表記との違い) を参照してください。

> **方針**: 対応する言語、DNCL との違い、文法の決め方は [日本語モードの方針](./dncl/policy.md) を参照してください。

## 1. 概要

smalruby の日本語モードは、大学入学共通テスト「情報I」の**共通テスト用プログラム表記**に合わせた日本語のプログラミング言語です（情報関係基礎の DNCL とは別のもの。[方針](./dncl/policy.md)）。日本語で記述したコードは内部的に Ruby コードにトランスパイルされ、さらに Scratch ブロックに変換されて実行されます。

### 動作の仕組み

```
日本語のコード → (dncl-to-ruby.js: ja-notation) → Ruby コード → (ruby-to-blocks-converter) → Scratch ブロック → 実行
```

日本語は **ja-notation**（`packages/ja-notation/`）が構文木に読みます。**標準の形**（共通テスト用プログラム表記に合わせた書き方。行番号、`｜` / `⎿`、字下げと行末の `:`、`の間繰り返す` / `増やしながら繰り返す`、同一行複数代入、`and` / `or`、前置の `not`、`関数 名前(引数):`。`名前(引数) を定義する:` も読む）も **DNCL 風の形**も、同じ解析で読みます。

ブロック → Ruby → 日本語の逆方向の変換も可能です（`ruby-to-dncl.js`）。書き出しは**標準の形**（字下げ 4 つと行末の `:`、`and` / `or` / `not`、`％`、`値 を返す`）です。行番号と `｜` / `⎿` は書き出しません。中身の無いブロックなど、字下げだけでは閉じる位置が分からないところは `を実行する` などの行を残します（`docs/dncl/README.md`「書き出しの形」）。

### 標準の形と DNCL 風の形

日本語モードは、どちらの形も読み込めます。表示と書き出しは標準の形です（[方針](./dncl/policy.md)）。

- **ブロック終端**:
  - 標準の形: 字下げを戻す（または `⎿` マーカー）で閉じる
  - DNCL 風の形: `を実行する` / `を繰り返す` / `と定義する` の行で閉じる（読み込みだけ）
  - **読み込み**: `⎿` の数だけブロックを閉じる
- **条件分岐の末尾コロン**:
  - 標準の形: `もし 条件 ならば:`
  - DNCL 風の形: `もし 条件 ならば`（コロンなし）
  - **読み込み**: どちらも読む（`:` のあるブロックは字下げで閉じる）
- **`繰り返す` 接尾辞**:
  - 標準の形: `条件 の間繰り返す:` / `i を ... 増やしながら繰り返す:`
  - DNCL 風の形: `条件 の間` / `i を ... 増やしながら`
  - **読み込み**: どちらも読む
- **関数定義**:
  - 標準の形: `関数 名前(引数):` と字下げ（`と定義する` の行は置かない）
  - DNCL 風の形: `関数 名前(引数)` ... `と定義する`
  - **読み込み**: どちらも読む（`名前(引数) を定義する:` も読む）
- **戻り値**:
  - 標準の形: `値 を返す`
  - DNCL 風の形: `返す 値`
  - **読み込み**: どちらも読む
- **代入**:
  - 標準の形: `a = 1`
  - DNCL 風の形: `a ← 1`
  - **読み込み**: どちらも読む
- **論理演算子**:
  - 標準の形: `a > 0 and b == 1` / `a > 0 or b > 0`
  - DNCL 風の形: `a > 0 かつ b == 1` / `a > 0 または b > 0`
  - **読み込み**: どちらも読む（名前の一部の `and` などは演算子と取らない）
- **同一行複数代入**:
  - 標準の形: `a = X, b = Y`（ブロックでは 2 つの代入）
  - **読み込み**: 1 行の複数代入も読む。書き出しは 1 行に 1 つの代入
- **その他**:
  - 内部的に Scratch ブロックに変換されるため、**使用できる機能が Scratch の範囲に限定される**
  - 変数に `@` や `$` プレフィックスは使えない（Ruby の変数記法は自動的に処理される）

詳細な対応一覧は [`docs/dncl/README.md`](dncl/README.md) の「書き出しの形」と「標準の形の読み込み」セクションを参照してください。記法ごとの決め方は [基本設計](./dncl/design.md) の 3 章です。

## 2. プログラム構造

### トップレベル構造

日本語モードのプログラムは、文（Statement）の連続で構成されます。class 定義や module 定義は使用しません。

```
# 変数の初期化
a = 0

# メインロジック
もし a > 0 ならば:
    表示する(a)
```

### インデント

ブロック構造は、始まりの行の終わりの `:` と、その下の字下げで表現します。字下げを戻した行でブロックが終わります。書き出しは空白 4 つの字下げです（読み込みは 2 つ・全角空白・タブでもよい）。

```
もし a > 0 ならば:
    表示する("正の数")
そうでなければ:
    表示する("正でない")
```

エディタは、行番号 `(01)` と、字下げの位置の縦線・L 字の罫線を見た目だけ描きます（読むモード。[`docs/dncl/README.md`](dncl/README.md)「読むモードと書くモード」）。テキストには行番号と罫線を書きません。行番号と罫線つきのテキスト（「行番号と罫線つきでコピー」の形）を貼り付けると、行番号と罫線を外して字下げの形に戻します。

### 冒頭の説明文（設定）

問題文で約束されること（配列の添字の始まり、コメントの記号、論理演算子の説明）は、プログラムの**冒頭のコメント**に、公式の問題文と同じ型の文で書きます（[基本設計](./dncl/design.md) の 4 章）。決まった文だけを設定として読み、それ以外のコメントは普通のコメントです。説明文が無いプログラムは、例示の形（添字は 0 から・コメントは `#`）とみなします。

```
# すべての配列の添字は 1 から始まる。
# 「and」は「かつ」を意味する論理演算子であり，左右の式がともに真のときにだけ真となる。
Data = [3, 1, 2]
表示する(Data[1])
```

エディタのその他メニュー（⋯）の見出し「問題の約束」の下の項目で、よくある設定のパターンを選んで書くこともできます（[`docs/dncl/README.md`](dncl/README.md)「設定（冒頭の説明文）」）。

### コメント

`#` 以降が行コメントになります。

```
# これはコメントです
a = 1 # 行末コメント
```

コメントの記号を `//` にする問題もあります。プログラムの冒頭に `// 「//」から行の終わりまでは，処理の対象とならない。` と書くと、`//` から行の終わりまでがコメントになります（`#` もコメントのまま）。このとき `//` は整数の割り算に使えないので、商は `÷` で書きます。Ruby では `#` のコメントになり、日本語に戻すときは `//` で書かれます。

## 3. データ型

### リテラル

| 型 | 構文 | 例 | 備考 |
|---|---|---|---|
| 整数 | `数字の並び` | `42`, `0`, `-5` | |
| 浮動小数点数 | `数字.数字` | `3.14`, `1.0` | |
| 文字列 | `"..."` または `「...」` | `"hello"`, `「テスト」` | `「」` は `""` に自動変換 |
| 真偽値 | `真` / `偽` | `真`, `偽` | Ruby の `true` / `false` に変換 |
| 配列 | `[値1, 値2, ...]` | `[1, 5, 10]` | |

### 文字列リテラル

ダブルクォート `"..."` と日本語カギカッコ `「...」` の両方が使えます。カギカッコはトランスパイル時にダブルクォートに変換されます。`"..."` / `'...'` の中に書いたカギカッコは文字列の文字なので、そのまま残ります。`「...」` の中の `"` と `\` も文字なので、Ruby では `\"` / `\\` と書きます（`「a"b」` → `"a\"b"`）。

```
a = "hello"
b = 「こんにちは」  # → "こんにちは" に変換
c = "「く」がある"  # → "「く」がある" のまま
```

## 4. 変数

### 命名規則

| 先頭文字 | 内部変換 | 例 | Ruby 変換後 |
|---|---|---|---|
| 小文字 (`a-z`) | インスタンス変数 | `a`, `score` | `@a`, `@score` |
| 大文字（スカラー値） | 名前付き変数 | `A`, `Max` | `@_var_A_`, `@_var_Max_` |
| 大文字（配列値） | 名前付き配列 | `Kouka`, `Data` | `@_array_Kouka_`, `@_array_Data_` |

大文字で始まる変数名が配列かスカラーかは、ソースコード内で配列リテラルの代入（`X = [...]`）、配列アクセス（`X[i]`）、`要素数(X)` の使用、または要素の追加（`X に 値 を追加する`）があるかどうかで自動判定されます。

### 識別子に使える文字

- ASCII 英字（`a-z`, `A-Z`）、アンダースコア（`_`）、2 文字目からは数字（`0-9`）
- ひらがな・カタカナ・漢字（CJK 拡張の漢字も）と、`々` `〆` `ヶ` `ー` など名前に使う文字。ギリシャ文字など、ほかの文字体系の文字も使えます（`佐々木`、`α`）
- 全角英字・全角数字は半角として読みます（`ｘ１` は `x1` と同じ変数）。文字列とコメントの中は書いたとおりです
- `☆` `①` のような記号は使えません

範囲の詳細は `docs/dncl/README.md` の「名前に使える文字」を参照してください。

### 禁止文字

変数名に `@` や `$` を使うことはできません。使用した場合、バリデーションエラーが表示されます。

```
# ❌ エラー: 日本語モードでは変数に「@」は使えません
@a = 10

# ✅ 正しい書き方
a = 10
```

### 代入

| 構文 | 例 | Ruby 変換後 |
|---|---|---|
| `変数 = 式` | `a = 10` | `@a = 10` |
| `変数 = 式, 変数 = 式` | `a = 1, b = 2` | `@a = 1` と `@b = 2` の 2 行（日本語に戻すと 2 行） |
| `変数 ← 式`（DNCL 風の形。読むだけ） | `a ← 10` | `@a = 10` |

代入は `=` で書きます。DNCL 風の形の矢印 `←` も読みます（`=` と同等。書き出しは `=`）。文字列（`「...」` / `"..."` / `'...'`）とコメントの中の `←` は文字なので、そのまま残ります（`表示する(「x←1」)` → `console.puts("x←1")`）。

```
a = 10              # 通常の代入
hidari = 0, migi = 5  # 1 行に 2 つの代入
Kouka = [1, 5, 10]  # 配列の初期化
```

## 5. 演算子

### 算術演算子

| 演算子 | 説明 | 例 | Ruby 変換後 |
|---|---|---|---|
| `+` | 加算 / 文字列結合 | `a + b` | `@a + @b` |
| `-` | 減算 | `a - 1` | `@a - 1` |
| `*` | 乗算 | `a * 2` | `@a * 2` |
| `/` | 割り算（小数になる。`7 / 2` は `3.5`） | `a / 3` | `@a / 3` |
| `÷` | 商の整数値（`7 ÷ 2` は `3`。負の数は小さいほうへ丸めるので `-7 ÷ 2` は `-4`） | `a ÷ 3` | `(@a / 3).to_i` |
| `//` | 商の整数値（`÷` と同じ。`-7 // 2` は `-4`。スモウルビーの書き方） | `10 // 3` | `(10 / 3).to_i` |
| `％` | 剰余（書き出しは全角の `％`。半角の `%` も読む） | `a ％ 2` | `@a % 2` |

`+` で文字列と数をつなぐときは、数を変数か `文字列(…)` にする（`"残り" + a`、`"残り" + 文字列(3)`）。文字列と数のリテラルをそのまま `+` でつなぐ書き方（`"残り" + 3`、`s = "a" + 1`）は、Ruby では文字列と数を足せない誤りになり、ブロックにもできないので、日本語の行に「文字列と数を「+」でつなぐときは、数を「文字列(3)」のように文字列にしてください…」のエラーが出る（数を `"残り3"` のように文字列の中に書いてもよい）。

`/` と `÷` の意味は共通テスト用プログラム表記に合わせている（`/` はふつうの割り算、`÷` は商の整数値）。`//` は、冒頭の説明文でコメントの記号を `//` にしたプログラムでは使えない（商は `÷` で書く）。`÷` は `*` / `/` / `％` と同じ強さで左から計算する（`a * 3 ÷ 2` は `(a * 3) ÷ 2` で、`(@a * 3 / 2).to_i`。`a ÷ 2 * 3` は `(@a / 2).to_i * 3`）。

負の数の商の丸め方は共通テスト用プログラム表記では決まっていないので、スモウルビーでは小さいほうの整数にする（`-7 ÷ 2` は `-4`。`整数(式)` も同じ）。符号は `÷` より強く結びつくので、`-a ÷ 2` は `(-a) ÷ 2`（`a` が 7 なら `-4`。Ruby は `(-@a / 2).to_i`）。商に符号を付けるときは `-(a ÷ 2)` と書く（`-3`。Ruby は `-((@a / 2).to_i)`）。日本語に戻すときは、名前や式に付いた符号が `÷` の左にあれば `(-a) ÷ 2` とかっこを付ける（負の数は `-7 ÷ 2` のまま）。Ruby の `.to_i` は 0 のほうへ切り捨てるので、負の数では Ruby と値が違う（[言語仕様の「Ruby との違い（注意）」](./smalruby-language-spec.ja.md#ruby-との違い注意)）。

Ruby → 日本語では、`(A / B).to_i` を `A ÷ B` にする（`A` は `*` / `/` / `%` でつないだ式でもよい。`((@a + @b) / 2).to_i` → `(a + b) ÷ 2`、`(@a * 3 / 2).to_i` → `a * 3 ÷ 2`）。`.to_i` の無い `/` は `/` のまま。それ以外の `(式).to_i` は `整数(式)` にする（`(@a / 2 * 3).to_i` → `整数(a / 2 * 3)`）。どれも日本語 → Ruby で同じ値に戻る。

### 比較演算子

| 演算子 | 説明 | 例 |
|---|---|---|
| `=` | 等しい（条件式内） | `a = 10`（※文脈依存） |
| `==` | 等しい | `a == 10` |
| `!=` | 等しくない | `a != 0` |
| `<` | 小さい | `a < 10` |
| `>` | 大きい | `a > 0` |
| `<=` | 以下 | `a <= 10` |
| `>=` | 以上 | `a >= 0` |
| `≦` | 以下（全角） | `a ≦ 10` |
| `≧` | 以上（全角） | `a ≧ 0` |

> **注意**: `=` の代入と比較の区別は文脈（文の先頭 = 代入、条件式内 = 比較）で判断されますが、曖昧さを避けるため条件式では `==` の使用を推奨します。

### 論理演算子

書き出しは、いつも `and` / `or` / `not` です。DNCL 風の形の `かつ` / `または` / `でない` も読みます。

| 演算子 | 説明 | 例 | Ruby 変換後 |
|---|---|---|---|
| `and` | 論理積 | `a > 0 and b < 10` | `@a > 0 && @b < 10` |
| `or` | 論理和 | `a > 0 or b > 0` | `@a > 0 \|\| @b > 0` |
| `not` | 論理否定（前置） | `not a` | `!@a` |
| `かつ` / `または`（DNCL 風の形。読むだけ） | 論理積 / 論理和 | `a > 0 かつ b < 10` | `@a > 0 && @b < 10` |
| `でない`（DNCL 風の形。読むだけ。後置） | 論理否定 | `a でない` | `!@a` |

`not` は比較演算より弱く、`and` / `or` より強く結び付きます（`not a > 10` は `!(@a > 10)`）。書き出しは、否定する範囲が式のときかっこを残します（`not (a > 10)`）。名前の一部（`nothing`・`knot`）と、文字列・コメントの中は演算子にしません。

> **注意**: DNCL 風の形の `かつ`、`または`、`でない` は、**名前の一部でなければ**演算子になります。前後が空白でなくても、かっこ・`]`・数値・文字列に続くときは演算子です（`(a > 0)かつ(b > 0)` → `(@a > 0) && (@b > 0)`、`a[1]かつ b` → `@a[1] && @b`、`(a > 0)でない` → `!(@a > 0)`）。前後に名前の文字（ひらがな・カタカナ・漢字・英字・数字・`_`）が続くときは名前の一部です（`かつお`、`または2`、`たかつき`）。名前とキーワードがくっついていると区別できないので（`真かつ偽`、`aかつb`）、名前とキーワードの間はスペースで区切ってください。文字列とコメントの中は変換しません。

#### `でない`（DNCL 風の形）が否定する範囲

`でない` は**直前の条件全体**を否定します。論理演算は比較演算より弱く、`でない` は `かつ` / `または` より強く結び付きます。否定する範囲は、すぐ前の `かつ` / `または`・`,`・代入の `=` / `←`・開きかっこまでです。

| DNCL 風の形 | Ruby 変換後 |
|---|---|
| `a > 10 でない` | `!(@a > 10)` |
| `a == b でない` | `!(@a == @b)` |
| `x でない かつ y` | `!@x && @y` |
| `a > 1 かつ b < 2 でない` | `@a > 1 && !(@b < 2)` |
| `(a > 10 かつ b) でない` | `!(@a > 10 && @b)` |
| `表示する(x でない)` | `console.puts(!@x)` |

`かつ` / `または` でつないだ条件をまとめて否定するときは、かっこで囲みます。Ruby → 日本語の変換は標準の形なので、`!f(x)` は `not f(x)`、`!(a > 10)` は `not (a > 10)` になります。

## 6. 制御構造

### 条件分岐（もし〜ならば）

```
もし 条件 ならば:
    文...
```

`なら` と `ならば` の両方が使えます。ラウンドトリップ変換では `ならば` に正規化されます。行の終わりの `:` は全角の `：` でも読みます。DNCL 風の形（`:` を書かずに `を実行する` の行で閉じる）も読みます。

#### if-else

```
もし 条件 ならば:
    文...
そうでなければ:
    文...
```

#### if-elsif-else

```
もし 条件1 ならば:
    文1...
そうでなくもし 条件2 ならば:
    文2...
そうでなければ:
    文3...
```

読むモードでは、if/else の縦線は最後の枝だけ L 字で閉じます（途中の枝は縦線のまま `そうでなければ:` で区切る）。

### 繰り返し（条件ループ）

#### 条件の間繰り返す（while ループ）

```
条件 の間繰り返す:
    文...
```

例:

```
a > 0 の間繰り返す:
    a = a - 1
```

「繰り返す」を省いた形（`条件 の間:`）と、DNCL 風の形（`条件 の間` ～ `を繰り返す`）も読みます。

「〜まで繰り返す」のブロック（Ruby の `until 条件`）は `not 条件 の間繰り返す:` になります。`until a > 10 && b` のように `and` / `or` でつないだ条件は `not (a > 10 and b) の間繰り返す:` とかっこで囲みます。逆に日本語 → Ruby では、条件全体が 1 つの `not`（DNCL 風の形では `でない`）で否定されている `の間` は `until` に戻り、ブロックも「〜まで繰り返す」のままです（`not a > 10 の間繰り返す:` → `until @a > 10`）。「〜まで待つ」のブロック（`wait until 条件`）は共通テスト用プログラム表記に無いので、中身が空の `not 条件 の間繰り返す:` になります（中身が無いので、閉じの行 `を繰り返す` を残します。[`docs/dncl/README.md`](dncl/README.md)「書き出しの形」）。

**中身が空の繰り返しは「〜まで待つ」になります。** 中身が空の `条件 の間繰り返す:` をブロックに戻すと、「〜まで繰り返す」ではなく「〜まで待つ」になります（`not 条件 の間繰り返す:` は「条件 まで待つ」、`条件 の間繰り返す:` は「（条件 ではない）まで待つ」）。

- 中身が空の「〜まで繰り返す」のブロック（Ruby の `until 条件 do` ～ `end`）も、日本語モードでは同じ中身が空の `not 条件 の間繰り返す:` になるので、日本語モードを通す（日本語モードで表示して、どこかを書きかえてブロックに戻す）と「〜まで待つ」に変わります。
- **動きは同じです**: どちらも、条件が成り立つまで何もしないで待ちます。
- **理由**: 日本語モードには共通テスト用プログラム表記に無い書き方を足さないためです。共通テスト用プログラム表記には「〜まで待つ」にあたる書き方が無く、中身が空の「〜まで繰り返す」と「〜まで待つ」を書き分ける方法がありません。どちらか 1 つに決める必要があり、「〜まで待つ」を日本語モードに通しても変わらないほうを選んでいます。
- 中身のある繰り返しは、これまでどおり「〜まで繰り返す」のままです。

#### 範囲繰り返し（for ループ）

**昇順（増やしながら）:**

```
変数 を 開始値 から 終了値 まで 増分 ずつ増やしながら繰り返す:
    文...
```

例:

```
i を 1 から 10 まで 1 ずつ増やしながら繰り返す:
    表示する(i)
```

**降順（減らしながら）:**

```
変数 を 開始値 から 終了値 まで 減分 ずつ減らしながら繰り返す:
    文...
```

例:

```
i を 10 から 0 まで 1 ずつ減らしながら繰り返す:
    表示する(i)
```

「繰り返す」を省いた形と、DNCL 風の形（`〜ずつ増やしながら` ～ `を繰り返す`）も読みます。

> **注意**: 終了値は**含まれます**（inclusive）。`1 から 10 まで` は 1, 2, 3, ..., 10 を繰り返します。

#### 後判定の繰り返しは書けない

日本語モードの繰り返しは、`〜の間繰り返す`（前判定）と `〜ずつ増やしながら繰り返す` / `〜ずつ減らしながら繰り返す` だけです。**後判定の繰り返し**（先に 1 回動かしてから条件を確かめる繰り返し）には対応しません。

- **理由**: 日本語モードは共通テスト用プログラム表記に合わせています。共通テスト用プログラム表記の繰り返しは「〜の間繰り返す」（前判定）と「〜を…から…まで…ずつ増やしながら繰り返す」だけで、後判定の「繰り返し，…を，〜になるまで実行する」は旧課程「情報関係基礎」の旧 DNCL にしかありません。情報Ⅰの授業で使わない書き方は、書けないと伝えるほうが学習の役に立つためです。
- **エラーになるもの**: Ruby の `begin ... end while 条件` / `begin ... end until 条件`（「〜まで繰り返す」の前に本体を 1 回置いたブロックから作られる形）と、旧 DNCL の `繰り返し` … `を 〜 になるまで実行する`。日本語モードに切りかえるとき・日本語モードで表示したとき・日本語モードで書いたときに、その行に「後判定の繰り返し（先に 1 回動かしてから条件を確かめる繰り返し）は日本語では書けません。…」のエラーが出ます。このとき日本語モードの内容は Ruby に変換しません（`@begin` のような Ruby にはなりません）。Ruby モードではそのまま書けます。
- **書き直し方**: 最初の 1 回をループの前に書いてから、「〜の間繰り返す」にします。

```
# Ruby（後判定）: begin; a = a + 1; end until a >= 3
a = a + 1
a < 3 の間繰り返す:
    a = a + 1
```

#### 日本語モードに無い命令は書けない

Ruby の命令やメソッド呼び出し（`move(2)`、`bounce_if_on_edge`、`with_screen_refresh do`、`[1, 2].each do |x|` など）は日本語モードでは書けません。日本語モードに切りかえるとき・日本語モードで表示したとき・日本語モードで書いたときに、その行に「「move」は日本語モードでは書けない命令です。Ruby モードでは書けます。」のエラーが出ます。このとき日本語モードの内容は Ruby に変換しません（`@move(2)` のような Ruby にはなりません）。

- 使える呼び出しは、`表示する` / `要素数` / `乱数` などの組み込み関数と、`関数 名前(…)` で定義した関数です。
- 日本語の名前（定義し忘れた関数や、共通テストの問題文で「用意されている」とされる `差分(...)` など）を呼ぶと、「「差分」は定義されていない関数です。「関数 差分(…):」で定義してください。」のエラーが出ます。
- 繰り返しを抜ける・次の回へ進む Ruby の `break` / `next`（`break if i == 5` も）は、共通テスト用プログラム表記に当たる書き方が無いので、同じエラーになります。条件を `〜の間繰り返す` の条件や `もし` に書きかえてください。
- 命令と同じ名前の変数（`move = 1`）は書けます。名前の後に `(` が付いたとき（または 1 行に名前だけを書いたとき）に命令と見なします。

### ブロックの終わり

標準の形では、字下げを戻した行でブロックが終わります。終わりの行は書かなくてかまいません（書いてもよい。下の「標準の形でも、終わりの行を書いてよい」）。

DNCL 風の形の終端キーワードも読みます（読み込みだけ。書いてあってもエラーにせず、消したり直したりもしません）。書き出しで残すのは、字下げだけでは閉じる位置が分からないとき（中身の無いブロックなど）だけです。

| 終端キーワード（DNCL 風の形） | 対象 |
|---|---|
| `を実行する` | `もし〜ならば`（条件分岐） |
| `を繰り返す` | `の間`（while ループ）、`ずつ増やしながら/減らしながら`（for ループ） |
| `と定義する` | `関数〜`（関数定義） |

ブロックの種類に合わない終端キーワードで閉じると誤りです（`もし〜ならば` を `を繰り返す` で閉じるなど。「「もし〜ならば」は「を繰り返す」ではなく「を実行する」で閉じてください」）。`end` はどのブロックも閉じます。

**標準の形でも、終わりの行を書いてよい。** 標準の形（見出しの行の終わりに `:` を付けて、字下げでブロックを閉じる形）でも、どのブロックの終わりにも上の終端キーワードの行を書けます。書いても書かなくても、同じ Ruby になります。書き出し（ブロックや Ruby から日本語にするとき）では足しません。

```
関数 合計(n):
    s = 0
    i を 1 から n まで 1 ずつ増やしながら繰り返す:
        もし i % 2 == 0 ならば:
            s = s + i
        を実行する
    s を返す
と定義する
```

- 終わりの行は、いちばん内側の開いているブロックを閉じます。見出しの行と同じ字下げでも、中身と同じ字下げ（それより深くても）でもかまいません。中身の無いブロックを、字下げした終わりの行で閉じてもかまいません。
- 終わりの行がある形と無い形は、混ぜて書けます（上の例では、`を繰り返す` の行を省いています）。外側のブロックの終わりの行は、字下げだけで閉じていた内側のブロックも閉じます。
- 罫線の `⎿` で閉じたブロックのすぐ後の終わりの行（`⎿` の行に書いたものも）は、同じ終わりをもう一度書いたものとして読みます（後ろの `# コメント` は残ります）。続けてもう 1 行書いた終わりの行は、閉じるブロックが無いのでエラーになります。

## 7. 関数

### 関数定義

```
関数 関数名(引数1, 引数2):
    文...
```

例:

```
関数 add(a, b):
    a + b を返す
```

`関数名(引数) を定義する:` の形と、DNCL 風の形（`関数 関数名(引数)` ～ `と定義する`）も読みます。

### 引数は変えられない

関数の引数には代入できない（ブロック定義の引数は変えられないため）。`a = b` や `a += 1` のように引数を
変える行は「『a』は引数なので、値を変えられません」のエラーになる。引数の値を変えたいときは、
ほかの変数に写してから、その変数を変える。

```
関数 saidaikouyakusuu(a, b):
    x = a
    y = b
    y != 0 の間繰り返す:
        amari = x ％ y
        x = y
        y = amari
    x を返す
```

### 戻り値

```
式 を返す
```

例:

```
関数 f(x):
    x * 2 を返す
```

DNCL 風の形の `返す 式` も読みます。

## 8. 組み込み関数

### 入出力

| 関数 | 説明 | 例 | Ruby 変換後 |
|---|---|---|---|
| `表示する(式)` | 値をコンソールに 1 行表示する | `表示する(a)` | `console.puts(@a)` |
| `【外部からの入力】` | コンソールで入力を受け取る（答えをそのまま使う） | `a = 【外部からの入力】` | `@a = console.gets` |
| `【整数を入力】` | コンソールで入力を受け取って整数にする | `n = 【整数を入力】` | `@n = console.gets.to_i` |
| `【文字列を入力】` | コンソールで入力を受け取る（読むだけ。書き出しは `【外部からの入力】`） | `s = 【文字列を入力】` | `@s = console.gets` |

`表示する` は複数の引数を受け取れます。文字列リテラル以外の引数は `.to_s` が自動付与され、`+` で連結された **コンソールの 1 行** として表示されます。式の引数は、引数全体に `.to_s` が付くようにかっこで囲みます（`not` は先に `!` にします）:

```
表示する(a, b, c)              # → console.puts(@a.to_s + @b.to_s + @c.to_s)
表示する(atai, "は", aida)     # → console.puts(@atai.to_s + "は" + @aida.to_s)
表示する(a + 1, b)             # → console.puts((@a + 1).to_s + @b.to_s)
表示する(not x, y)             # → console.puts((!@x).to_s + @y.to_s)
```

> **重要 (不可逆性)**: `表示する(...)` と `【外部からの入力】` は、**コンソールの拡張機能**のブロック（[`docs/extension-smalruby-console/`](extension-smalruby-console/README.md)）になり、Ruby では `console.puts(...)` / `console.gets` と書きます（「言う」`say` / `puts` や「聞いて待つ」ではない）。`表示する` はキャラクターの吹き出しではなくコンソールへの出力だからです。「言う」や「聞いて待つ」で作ったプログラムも `表示する` / `【外部からの入力】` として読みますが、日本語から変換し直すとコンソールのブロックになります。ステージの上のコンソールのボタンで、ステージとコンソールを切りかえます。詳細は [Block ↔ Ruby ↔ DNCL 変換マトリクス](dncl/README.md#block--ruby--dncl-の変換マトリクス) を参照。

`【外部からの入力】` / `【整数を入力】` は代入文の右辺で使用します:

```
a = 【外部からの入力】
# ↓ Ruby 変換後
# @a = console.gets
```

### 型変換

| 関数 | 説明 | 例 | Ruby 変換後 |
|---|---|---|---|
| `整数(式)` | 整数に変換（その数以下でいちばん大きい整数。`整数(3.7)` は `3`、`整数(-3.5)` は `-4`） | `整数(x)` | `@x.to_i` |
| `文字列(式)` | 文字列に変換 | `文字列(x)` | `@x.to_s` |

引数が式のときは、式全体をかっこで囲んでから `.to_i` / `.to_s` を付ける（`整数(a + 1)` → `(@a + 1).to_i`、`文字列(not x)` → `(!@x).to_s`）。かっこが無いと最後の項だけが変換されるため。下の `四捨五入` / `切り捨て` / `切り上げ` / `絶対値` / `要素数` / `含む` の 1 つめの引数も同じ。Ruby → 日本語では `(式).to_i` を `整数(式)` に戻す。ただし式が 1 つの割り算のとき（`(x / 2).to_i`）は商の整数値なので `x ÷ 2` に戻す（上の「算術演算子」）。

### 数値

| 関数 | 説明 | 例 | Ruby 変換後 |
|---|---|---|---|
| `乱数(n)` | 0 以上 n 未満の整数の乱数（n は 1 以上の整数。`乱数(10)` は 0〜9） | `乱数(10)` | `rand(10)` |
| `乱数(a..b)` | a 以上 b 以下の乱数 | `乱数(1..10)` | `rand(1..10)` |
| `四捨五入(式)` | 四捨五入（ちょうど半分は大きいほうへ。`四捨五入(2.5)` は `3`、`四捨五入(-2.5)` は `-2`） | `四捨五入(3.7)` | `3.7.round` |
| `切り捨て(式)` | その数以下でいちばん大きい整数（`切り捨て(3.7)` は `3`、`切り捨て(-2.5)` は `-3`） | `切り捨て(3.7)` | `3.7.floor` |
| `切り上げ(式)` | その数以上でいちばん小さい整数（`切り上げ(3.2)` は `4`、`切り上げ(-2.5)` は `-2`） | `切り上げ(3.2)` | `3.2.ceil` |
| `絶対値(式)` | 絶対値 | `絶対値(-5)` | `-5.abs` |
| `平方根(式)` | 平方根 | `平方根(9)` | `Math.sqrt(9)` |

関数の前の `-` は、関数の値にマイナスを付ける（`-絶対値(5)` は `-5`）。Ruby では `-5.abs` が `(-5).abs`（`5`）と読まれるので、Ruby にするときはかっこを付けて `-(5.abs)` とする。`整数` / `文字列` / `四捨五入` / `切り捨て` / `切り上げ` / `絶対値` / `要素数` / `含む` で同じ。Ruby → 日本語では `-(5.abs)` を `-絶対値(5)` に、`-5.abs` を `絶対値(-5)` に戻す。引き算（`a - 絶対値(5)` → `@a - 5.abs`）はかっこを付けない。

### 文字列操作

| 関数 | 説明 | 例 | Ruby 変換後 |
|---|---|---|---|
| `含む(文字列, 検索文字列)` | 文字列に検索文字列が含まれるか | `含む("hello", "ell")` | `"hello".include?("ell")` |

### 配列操作

| 関数 | 説明 | 例 | Ruby 変換後 |
|---|---|---|---|
| `要素数(配列)` | 配列/文字列の要素数（長さ）を取得 | `要素数(Kouka)` | `@_array_Kouka_.length` |

要素の追加は文で書きます（関数ではありません）。

| 文 | 説明 | 例 | Ruby 変換後 | ブロック |
|---|---|---|---|---|
| `配列 に 値 を追加する` | 配列の**最後**に要素を 1 つ足す | `Kouka に 20 を追加する` | `@_array_Kouka_.push(20)` | 「(20) を (Kouka) に追加する」 |

- `に` と `を追加する` の前後には空白を入れます（`Kouka に x + 1 を追加する`）。`に` の前に書けるのは配列の変数だけです（`A[0] に 3 を追加する` は誤り）。`を追加する` を書いた変数は配列とみなします。
- Ruby の `@_array_Kouka_.push(20)` と `@_array_Kouka_ << 20` は、日本語に戻すと `Kouka に 20 を追加する` になります（Ruby にするときはいつも `push`）。
- 先頭や途中に足す書き方はありません（例題に無いため。要るときはブロックの「(1) 番目に挿入する」を使います）。

### 配列アクセス

配列の要素にはインデックス（添字）でアクセスします。**添字は 0 から始まります**（最初の要素は `Kouka[0]`、要素が 3 個なら最後の要素は `Kouka[2]`）。

```
Kouka = [1, 5, 10]
a = Kouka[0]       # → 1
Kouka[0] = 100      # 要素の代入
```

共通テストのプログラム表記も、特に説明がない場合は添字を 0 から始めます。ただし問題文で「添字は 1 から始まる」と指定されることがあります。そのときは、プログラムの**冒頭**（最初のコードの行より前）に次の説明文をコメントで書くと、そのプログラムの添字は 1 から始まります。

```
# すべての配列の添字は 1 から始まる。
Ten = [7, 3, 9]
kamoku を 1 から 3 まで 1 ずつ増やしながら繰り返す:
    表示する(Ten[kamoku])   # 1 番目から 3 番目まで
```

Ruby にするときは添字を 1 ずらします（`Ten[kamoku]` → `@_array_Ten_[@kamoku - 1]`、`Ten[1]` → `@_array_Ten_[0]`）。Ruby やブロックから日本語に戻すときは元に戻ります。説明文はコメントなので、ブロックにしても、作品を保存して開き直しても残ります。

説明文は、エディタのその他メニュー（⋯）の「添字が 1 から始まる問題」を選んでも書けます（論理演算子 `and` / `or` / `not` の説明文もいっしょに書きます）。「例示の形（添字は 0 から）」を選ぶと説明文を消します。どちらも、プログラムの意味が変わらないように添字を書きかえます（`A[0]` ⇔ `A[1]`）。

説明文を書かないときは、**添字を 1 ずらして**書きます。

```
# 問題文: Ten の添字は 1 から始まる（Ten[1] が 1 つめの教科の点数）
Ten = [7, 3, 9]
kamoku を 1 から 3 まで 1 ずつ増やしながら繰り返す:
    表示する(Ten[kamoku - 1])   # Ten[kamoku] と書くと最後に範囲外になる
```

「添字は 1 から始まる」のような注釈（コメント）付きのプログラムを日本語モードのエディタに貼り付けると、冒頭に `# すべての配列の添字は 1 から始まる。` を書くか確認するダイアログが出ます。「はい」を選ぶと冒頭に説明文が書かれ、貼り付けた添字はそのまま（問題文と同じ意味）で動きます。書きこみは 1 回の Undo で元に戻せます。「いいえ」を選ぶと貼り付けたままになります。

範囲外の添字で要素を読むと、エラーにはならず空の値になります（Scratch のリストと同じ動き）。そのため日本語モードのエディタは、範囲外になる添字に警告（黄色の波線）を出し、添字が 0 から始まることと直し方を表示します。警告を出すのは、次のように範囲外になることがプログラムから確実に分かるときだけです。

- `i を 1 から N まで ...` の繰り返しの中の `X[i]` で、`i` の最大値が `X` の要素数以上のとき（`N` が数・一度だけ数を代入した変数・`要素数(X)` のどれか）
- `X[3]` のような数の添字が `X` の要素数以上のとき

対象は、配列リテラル（`X = [...]`）を一度だけ代入し、要素の追加・削除（`X に 値 を追加する`、`X.push(...)` / `X.insert(...)` / `X.delete_at(...)` / `X.clear` など）をしない配列です。関数の中では、引数と同じ名前の配列や変数は呼び出し元が渡す値になるので、警告の判定に使いません。

## 9. ブロックパレット（使用可能なブロック）

日本語タブで書いているあいだは、Scratch のブロックパレットから使用できるブロックが制限されます。

### 完全に非表示のカテゴリ

- **動き（Motion）** — 非表示
- **音（Sound）** — 非表示
- **イベント（Events）** — 非表示（共通テスト用プログラム表記にはイベント概念がない）

### 使用可能なブロック

| カテゴリ | 使用可能なブロック | 日本語の構文との対応 |
|---|---|---|
| **制御** | `〜回繰り返す`, `もし〜なら`, `もし〜でなければ`, `〜まで繰り返す` | 増やしながら繰り返す, もし, もし〜そうでなければ, 〜の間繰り返す |
| **演算** | すべて | 算術・比較・論理演算子 |
| **コンソール** | `〜を表示する`, `入力する` | `表示する()`, `【外部からの入力】` |
| **見た目** | `〜と〜秒言う`（`say for N secs`）のみ | `表示する()`（読むだけ） |
| **調べる** | `〜と聞いて待つ`（`ask`）, `答え`（`answer`）のみ | `【外部からの入力】`（読むだけ） |
| **変数** | すべて（変数の作成、代入、変化、表示/非表示） | 変数代入 |
| **リスト** | すべて（追加、削除、挿入、置換、取得、検索、長さ、含む、空判定） | 配列操作（`A に 値 を追加する` など） |
| **ブロック定義** | すべて（関数定義、関数呼び出し、引数） | `関数 名前(引数):` |

## 10. エディタ機能

### シンタックスハイライト

Monaco エディタで以下の要素がハイライトされます:

| 要素 | トークン種別 | 色の例 |
|---|---|---|
| 制御キーワード | `keyword` | `もし`, `ならば`, `の間繰り返す`, `ずつ増やしながら繰り返す`, `を返す`, `を追加する`（DNCL 風の形の `を実行する` も）等 |
| 組み込み関数 | `type.identifier` | `表示する`, `要素数` 等 |
| 論理演算子 | `keyword.operator` | `and`, `or`, `not`（DNCL 風の形の `かつ`, `または`, `でない` も） |
| 真偽値 | `constant.language` | `真`, `偽` |
| 入力プレースホルダ | `keyword` | `【外部からの入力】` |
| 文字列 | `string` | `"..."`, `「...」` |
| 数値 | `number` | `42`, `3.14` |
| コメント | `comment` | `# ...` |
| 演算子 | `operator` | `÷`, `％`, `//`, `≦`, `≧`, `←` |
| 括弧 | `delimiter.*` | `()`, `[]`, `{}`, `「」`, `【】`（Monarch の `brackets` に定義する） |

### オートインデント

以下のキーワードの後で自動的にインデントが増加します（行の終わりの `:` / `：` と、繰り返しの `繰り返す:` があってもなくても同じ）:

- `なら` / `ならば`（条件分岐の開始）
- `そうでなければ`（else 節）
- `そうでなくもし`（elsif 節）
- `の間`（while ループ）
- `ずつ増やしながら` / `ずつ減らしながら`（for ループ）
- `関数〜`（関数定義）

以下のキーワード（DNCL 風の形の閉じの行と、`もし` の続き）でインデントが自動的に減少します:

- `を実行する`
- `を繰り返す`
- `と定義する`
- `そうでなければ`
- `そうでなくもし`

### 自動補完スニペット

以下のスニペットが入力候補として表示されます。ブロックは**標準の形**（開始の行の終わりに `:`、中は空白 4 つの字下げ。`を実行する` などの閉じの行は入れない）で入ります:

| トリガー | 展開 |
|---|---|
| `もし...ならば` | `もし 条件 ならば:`<br>`    ` |
| `もし...そうでなければ` | `もし 条件 ならば:`<br>`    `<br>`そうでなければ:`<br>`    ` |
| `もし...そうでなくもし` | `もし 条件 ならば:`<br>`    `<br>`そうでなくもし 条件 ならば:`<br>`    `<br>`そうでなければ:`<br>`    ` |
| `繰り返し（増やす）` | `i を 1 から 10 まで 1 ずつ増やしながら繰り返す:`<br>`    ` |
| `繰り返し（減らす）` | `i を 10 から 0 まで 1 ずつ減らしながら繰り返す:`<br>`    ` |
| `条件の間繰り返す` | `条件 の間繰り返す:`<br>`    ` |
| `関数定義` | `関数 名前(引数):`<br>`    ` |
| `を返す` | `値 を返す` |
| `を追加する` | `配列名 に 値 を追加する` |
| `表示する` | `表示する()` |
| `【外部からの入力】` | `変数 = 【外部からの入力】` |
| `要素数` | `要素数(配列名)` |
| `整数` | `整数(値)` |
| `文字列` | `文字列(値)` |
| `乱数` | `乱数(範囲)`（範囲の代わりに 1 以上の整数 n を書くと 0 以上 n 未満の整数。`乱数(10)` は 0〜9） |

### 括弧の自動閉じ

以下のペアが自動で閉じられます:

- `()`, `[]`, `{}`
- `""`, `''`
- `「」`, `【】`

## 11. 共通テスト用プログラム表記との違い

共通テスト用プログラム表記には、まとまった仕様書がありません（[方針](./dncl/policy.md)）。日本語モードは、公式の例題（例示・試作問題・本試験・追試験）に合わせた**標準の形**で書き、例題に無いものは方針の決め方で決めています（記法ごとの根拠は [基本設計](./dncl/design.md) の 3 章）。ここでは、スモウルビーで決めたこと・できないことをまとめます。

### 書き方で決めたこと

| 項目 | smalruby3-editor |
|---|---|
| テキストと読むモード | テキストは字下げと行末の `:` で書き、行番号 `(01)` と罫線（縦線・L 字）はエディタが読むモードで見た目だけ描く。貼り付けた行番号と罫線は読む |
| 問題文の約束 | 添字の始まり・コメントの記号・論理演算子の説明を、冒頭の説明文（コメント）で設定する。説明文が無ければ例示の形（添字は 0 から・コメントは `#`） |
| 等価比較 | `==`（条件式の中の `=` も比較として読むが、`==` を推奨） |
| 割り算 | `/`（小数になる割り算）、`÷`（商の整数値）。`//` も商の整数値として使える（コメントの記号を `//` にしたときを除く）。負の数の商は小さいほうへ丸める（`-7 ÷ 2` は `-4`） |
| 全角の記号 | `％` `≦` `≧` `≠` `＋` などの全角の演算子、`：` `，` も読む。書き出しは半角（余りだけ `％`） |
| 全角英字・全角数字 | 文字列とコメントの外では半角として読む（`ｘ１` は `x1`、`１２` は `12`） |
| 入力 | `【外部からの入力】`（答えをそのまま使う）と `【整数を入力】`（整数にする） |
| 要素の追加 | `A に 値 を追加する`（最後に足す。例題に無いので、方針の決め方の ⑤ で決めた） |
| 戻り値 | `値 を返す`（例題に無いので、方針の決め方の ⑤ で決めた） |
| DNCL 風の形 | `を実行する` / `を繰り返す` / `と定義する` で閉じる形、`←`、`かつ` / `または` / `でない`、`返す 値` も読む（読み込みだけ） |

### できないこと

| 項目 | smalruby3-editor |
|---|---|
| 後判定の繰り返し | 未対応（エラー。最初の 1 回をループの前に書いて `〜の間繰り返す` にする） |
| 繰り返しを途中で抜ける | 未対応（Ruby の `break` / `next` はエラー） |
| 2 次元配列 | 未対応（Scratch のリストは 1 次元） |
| 配列の宣言（要素数だけを決める書き方） | 未対応（配列リテラル `A = [...]` で初期化） |
| Ruby の命令・メソッド呼び出し | 未対応（その行にエラー。組み込み関数と `関数` で定義した関数だけ呼べる） |
| 問題文で「用意されている」とされる関数 | 自分で `関数 名前(引数):` で定義する（定義しないとエラー） |

### 機能の違い

| 項目 | smalruby3-editor |
|---|---|
| 実行環境 | Scratch で実行。日本語タブでは、ステージの代わりにコンソールを出す（スマホでは、表示や入力のときに再生の画面へ移ってコンソールを出す） |
| 表示 | `表示する(式)` → コンソールに 1 行表示（コンソールの拡張機能） |
| 入力 | `【外部からの入力】` → コンソールで答えを受け取る |
| スコープ | すべて Scratch のスプライト変数に変換 |
| 配列操作 | `要素数(A)`、要素の追加 `A に 値 を追加する`。Scratch のリストブロックも使用可能 |
| ブロック | コードタブでは、日本語で書けるブロック（と「〜と〜秒言う」など読むだけのもの）に絞る |
| 誤りのあるとき | 読めない行があるあいだは、ほかのタブやスプライトへ移らない（書いた行が消えないように） |

### 内部実装の特徴

smalruby3-editor の日本語モードは、以下のアーキテクチャで動作します:

1. **双方向トランスパイル**: 日本語 ↔ Ruby の相互変換が可能（ラウンドトリップ対応。構文木を通す ja-notation）
2. **ソースマップ**: `【外部からの入力】` が 2 行に展開される際の行番号マッピングを管理
3. **バリデーション**: `@` や `$` の禁止文字チェックをトランスパイル前に実行
4. **配列名の自動検出**: ソース全体をスキャンして大文字変数の配列/スカラー判定を行う

### ブロックにできない行のエラー

日本語としては読めても、ブロックにできない行（多重代入で値が数・文字列だけでないもの、引数への代入、文字列と数のリテラルの `+` など）は、書いているあいだに（キーを止めて少しすると）その日本語の行にエラーが出る。コードタブへ行くときと同じ確かめで、文言も同じ（`「a, b = b, a」は命令がまちがっています。…`、`「a」は引数なので、値を変えられません。…`）。このエラーがあるあいだは、コードタブにもルビータブにも移らず、日本語タブにとどまってエラーの行を示す（ルビータブに移ると、日本語タブに戻れなくなるため）。

## 12. サポートされていない構文

以下の構文は日本語モードでは**使用できません**:

- class 定義 / module 定義 / include
- イベントハンドラ（`旗が押されたとき` 以外）
- 動き関連メソッド（`move`, `turn_right` 等）
- 音関連メソッド（`play`, `stop_all_sounds` 等）
- 見た目の大部分（`say` 以外の `think`, `show`, `hide` 等）
- 調べるの大部分（`ask`/`answer` 以外の `touching?`, `mouse.x` 等）
- `self.属性 = 値` 形式のプロパティ設定
- 正規表現
- `for` / `each` ループ
- `loop do...end`（無限ループ）
- `unless` / `case-when`
- 修飾子 if / unless
- `super`
- 複合代入演算子（`+=`, `-=` 等）
- `「変数 に 式 を入れる」` 形式の自然言語代入

## 13. 完全なサンプルプログラム

どれも標準の形です（記法をまねて作ったプログラム。センターの問題ではありません）。

### FizzBuzz

```
i を 1 から 30 まで 1 ずつ増やしながら繰り返す:
    もし i ％ 15 == 0 ならば:
        表示する("FizzBuzz")
    そうでなくもし i ％ 3 == 0 ならば:
        表示する("Fizz")
    そうでなくもし i ％ 5 == 0 ならば:
        表示する("Buzz")
    そうでなければ:
        表示する(i)
```

### 配列の合計

```
Data = [3, 1, 4, 1, 5, 9, 2, 6]
合計 = 0
i を 0 から 要素数(Data) - 1 まで 1 ずつ増やしながら繰り返す:
    合計 = 合計 + Data[i]
表示する(合計)
```

### 関数定義と呼び出し

```
関数 最大値(a, b):
    もし a > b ならば:
        a を返す
    そうでなければ:
        b を返す

x = 【整数を入力】
y = 【整数を入力】
表示する(最大値(x, y))
```

### 線形探索

```
Data = [5, 3, 8, 1, 9, 2, 7]
key = 【整数を入力】
found = 偽
i を 0 から 要素数(Data) - 1 まで 1 ずつ増やしながら繰り返す:
    もし Data[i] == key ならば:
        表示する(文字列(i) + "番目に見つかりました")
        found = 真
もし not found ならば:
    表示する("見つかりませんでした")
```

### 添字が 1 から始まる問題

```
# すべての配列の添字は 1 から始まる。
Tokuten = [70, 85, 60]
goukei = 0
i を 1 から 要素数(Tokuten) まで 1 ずつ増やしながら繰り返す:
    goukei = goukei + Tokuten[i]
表示する("合計は", goukei)
```

### 要素の追加

```
Kazu = []
i を 1 から 5 まで 1 ずつ増やしながら繰り返す:
    もし i ％ 2 == 1 ならば:
        Kazu に i を追加する
表示する(要素数(Kazu))
```
