# 日本語モードの基本設計（標準の形）

> **🆕 Smalruby 独自** — upstream に存在しない、Smalruby のために新規追加された機能

> **案（決定前）**: この文書は基本設計の案である。「決めること」の印（**【決める】**）が付いた項目は、
> 人間と 1 つずつ決めてから確定する。方針は [`policy.md`](./policy.md)。

## 1. 全体の考え方: テキストと見た目を分ける

試験のプログラムは、行番号と、左の縦線・L 字の罫線が付いた形で示される。しかし、この形を
そのまま**テキストとして**書かせると、1 行足すたびに行番号を振り直し、`｜` や `⎿` を手で打つことになり、
読む練習の前に入力でつまずく。

そこで、日本語モードを次の 2 つの層に分ける。

| 層 | 中身 | 決め方 |
|---|---|---|
| **テキスト**（エディタに入っている文字） | 字下げと、見出しの行の終わりの `:` でブロックを表す。行番号は書かない | 方針の「書くときは 1 つにそろえる」 |
| **見た目**（エディタが描く） | 行番号 `(01)` を行の左に、縦線と L 字を字下げの位置に描く | 公式の新しい年度の問題の見た目に合わせる |

- **貼り付け**（問題のプログラムを写したテキスト）は、行番号・`｜`・`⎿`・`└`・字下げだけのどれでも受け付け、
  テキストの形（字下げ + `:`）に直す（いまの「貼り付け時の整形」を広げる）。
- **コピー**は 2 通り用意する。テキストのまま／**問題の形**（行番号と罫線を文字で付けた形）。
- これで、支える読み方の ①（行番号と罫線を残したまま読めて動かせる）と ②（行番号で行を指せる）を、
  入力のしやすさを落とさずに満たす。

**【決める】A**: テキストと見た目を分けるか。分けない場合は、テキストに行番号と罫線を書く（いまの「標準の形」の貼り付けと同じ）。

## 2. 記法ごとの書き方

「書く」はブロックや Ruby から日本語にするときに出す形、「読む」は受け付ける形。根拠は方針の決め方の番号（① 例題、
② 例題に無いものは DNCL の言葉と例題の見た目、③ 揺れは新しい年度・DNCL、④ DNCL か Ruby に近いもの、⑤ 非公式の多数派か Ruby）。

| 記法 | 書く | 読む（受け付ける） | 根拠 |
|---|---|---|---|
| 行番号 | テキストには書かない。見た目で `(01)` | `(01)` `(1)` `( 1 )` 無し | ① 新しい年度は `(01)` |
| ブロック | 字下げ（全角 2 文字ぶんの見た目。テキストは空白 4 つ）。見た目で縦線と L 字 | 字下げだけ、`｜` `⎿` `│` `|` `└` | ① |
| if/else の閉じ方 | 見た目: 最後の枝だけ L 字。途中の枝は縦線のまま `そうでなければ:` で区切る | 枝ごとの L 字も読む | ① 例示・R7 追試 |
| 開始の記号 | 半角 `:` | `:` `：`、無し（DNCL 風の形） | ① |
| 代入 | `=`。1 行に複数の代入は `, ` | `,` `，` | ① |
| 表示 | `表示する(a, b)` | `表示する（…）`、`,` の後の空白の有無 | ① 新しい年度は `, ` |
| 入力 | **【決める】B** | `【外部からの入力】` `【整数を入力】` `【文字列を入力】` | ①・③ |
| 算術 | `+ - * /`、商 `÷`、余り `％`（全角）、べき乗 `**` | 半角 `%`、全角 `＋` `−` `×`、引き算の `−` `–` | ① 公式の説明は全角 `％` |
| 比較 | `== != < > <= >=` | `≠` `≧` `≦` `＜` `＞` | ① |
| 論理 | `and` `or` `not` | `かつ` `または` `でない`（DNCL 風の形） | ① |
| 分岐 | `もし 条件 ならば:` / `そうでなくもし 条件 ならば:` / `そうでなければ:` | DNCL 風の `を実行する` | ①（`そうでなくもし` は例示） |
| 数える繰り返し | `i を 1 から n まで 1 ずつ増やしながら繰り返す:`（減らしながら も） | 「繰り返す」を省いた形 | ①。差分が 1 以外は ② |
| 条件の繰り返し | `条件 の間繰り返す:` | 「繰り返す」を省いた形 | ① |
| 後判定の繰り返し | 出さない（ブロックに後判定が無い） | エラー | — |
| 繰り返しを抜ける | 出さない（ブロックに無い。いまもエラー） | エラー | — |
| 配列 | `A = [1, 2, 3]`、`A[i]`。添字の始まりは**設定** | `[ ]` | ① |
| 2 次元配列 | 出さない（Scratch のリストは 1 次元） | エラー | — |
| 要素数 | `要素数(A)` | — | ① |
| 要素の追加 | **【決める】C** | いまの書き方も読む | ⑤ |
| 関数の定義 | `関数 名前(引数):` と字下げ。`と定義する` の行は置かない | DNCL 風の `と定義する` | ② |
| 戻り値 | `値 を返す` | — | ⑤ |
| コメント | 設定（既定 `#`） | `#`、設定が `//` のときは `//` | ① 例示 |
| 文字列 | `"…"` | `「…」` `'…'` | ① |
| 変数名 | ブロックの名前のまま（日本語の名前も） | いまと同じ | — |

## 3. 設定と、よくある設定のパターン

設定にするのは、意味が変わるもの・問題文で約束されるものだけ（方針）。

| 設定 | 選べる値 | 既定 | 冒頭の説明文（公式の問題文の型） |
|---|---|---|---|
| 添字の始まり | 0 から / 1 から | 0 から（例示の既定） | `すべての配列の添字は 0 から始まる。` |
| コメントの記号 | `#` / `//` | `#` | `「#」から行の終わりまでは，処理の対象とならない。` |
| 論理演算子の説明 | 書く / 書かない | 書かない | `「and」は「かつ」を意味する論理演算子であり，左右の式がともに真のときにだけ真となる。` ほか |

- 「論理演算子の説明」は書き方を変えない（いつも `and` / `or`）。問題文と同じ説明を冒頭に置くかどうかだけ。
  **【決める】D**: 論理演算子を設定にするか（DNCL 風の `かつ` / `または` で書く設定にするか、説明文の有無だけにするか、設定にしないか）。
- `//` をコメントにしたときは、`//` を整数の商に使えない（商は `÷`）。

よくある設定のパターン（専門的でない受験者は、パターンを選ぶだけで済む）:

| パターン | 添字 | コメント | 論理演算子の説明 |
|---|---|---|---|
| 例示の形（既定） | 0 から | `#` | 書かない |
| 添字が 1 から始まる問題 | 1 から | `#` | 書く |

**【決める】E**: パターンの数と名前。DNCL 風の形をパターンとして残すか（方針は「読み込みは続ける」まで決めている）。

## 4. 冒頭の説明文

- 冒頭の説明文は、そのプログラムの**コメントの行**として書く。例（添字 1 から・`#`）:

  ```
  # すべての配列の添字は 1 から始まる。
  # 「and」は「かつ」を意味する論理演算子であり，左右の式がともに真のときにだけ真となる。
  ```

- **設定は、この説明文そのものから読み取る**（設定を別の場所に保存しない）。
  - Ruby のコメントはブロックのコメントとして作品に残るので、ブロックに直して保存しても、次に開いたときに
    同じ説明文が戻り、設定も戻る（作品ごと・スプライトごとの設定になる）。**実装の前に、この往復を確かめる。**
  - 説明文が無いプログラムは、既定（例示の形）とみなす。
- 設定を変えるのは、ツールバーのメニュー（パターンを選ぶ）。選ぶと冒頭の説明文を書きかえ、プログラムを
  その設定で表し直す。説明文を手で書きかえてもよい（決まった文だけを設定として読む。それ以外の文は普通のコメント）。

**【決める】F**: 設定をこの説明文から読み取る形にするか（ほかの案: 利用者ごとに保存する／作品のデータに保存する）。

## 5. 添字が 1 から始まる設定の変換

- 日本語の `A[i]` を Ruby の `@A[i - 1]` にする（ブロックのリストは 1 から数えるので、ブロックは `A[i]` の
  i 番目と同じ要素を読む）。Ruby から日本語に戻すときは `- 1` を外す（`@A[i - 1]` → `A[i]`、`@A[0]` → `A[1]`）。
- いまの「貼り付け時の添字の書き換え」（1 から始まる注釈のあるテキストの添字を 1 減らす）は、設定に置きかえる。
  注釈を見つけたら、書き換えではなく「添字が 1 から始まる設定にしますか」と聞く。
- 範囲外の添字の警告は、設定に合わせて判定する。

## 6. いまの形からの移り方

1. 読み込みは、標準の形と DNCL 風の形の両方を受け付けたまま、**書き出しを標準の形に切り替える**。
   - 作品はブロックとして保存されているので、表示の形を変えても作品は壊れない（日本語のテキストは保存していない）。
2. 生成AI に相談の質問文・答えの形を標準の形にする。
3. 教材・docs（`docs/smalruby-dncl-spec.ja.md`、`docs/dncl/README.md`、レッスン）を書きかえる。
4. DNCL 風の形は、読み込みだけ残す（貼り付け・既存の教材が動く）。
