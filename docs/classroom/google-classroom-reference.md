# Google Classroom の画面（参考）

クラス管理（先生・生徒の画面）のお手本にしている Google Classroom の、先生の画面の構成・言葉・操作の置き場所・見た目の値を記録する。

## この文書の目的

クラス管理は、スモウルビー本体とは別に**独自のデザイントークン**を使う。もとにするものは 2 つに分かれる。

| 何を | どこから | 文書 |
|---|---|---|
| UI 部品（ボタン・入力欄・メニュー・モーダル・タブなど）の形 | Scratch 由来 | [`docs/design-system/`](../design-system/README.md) |
| ページの構成・言葉・操作の置き場所 | Google Classroom 由来 | この文書 |

Google Classroom を使いこなしている先生が、説明なしでクラス管理を使えるようにするため。先生の画面の作り方の規約（R1〜R6・言葉の対応）は `.claude/rules/scratch-gui/classroom-ui.md`、いまの画面の仕様は [`ui-ux.md`](ui-ux.md) が正。この文書はそれらを置き換えず、お手本の側の事実だけを書く。

**確かめた範囲**: 2026-11 時点の Google Classroom の**先生の画面**（日本語 UI・テストデータ・幅 1484px 前後のウィンドウ）。生徒の画面は見ていない。Google は画面を変えることがあるので、ここに無いことや変わったことは、使う前にもう一度確かめる。

- Google の画面の画像は置かない（Google の著作物で、生徒の名前が写るため）。文字だけで書く。
- 値（px・色）は、画面から読み取ったおおよその値。「前後」と書いたものは幅がある。

## 画面ごとの構成

### 全体の枠

| 場所 | 中身 |
|---|---|
| 上の帯（高さ 64 前後） | 左から ≡（メインメニュー）→ ロゴと「Classroom」→ クラスの中では「›」とクラス名（2 行: 名前 / セクション）。右に ＋（クラスを作成またはクラスに参加・ホームだけ）・Google アプリ・アカウント |
| 左のレール（幅 76） | ホーム / カレンダー / 指導科目（開くと「確認が必要な課題」と各クラス） / アーカイブされたクラス / 設定。選ばれた項目は薄い青の丸い地 |
| 本文 | 白い面。左上の角が大きく丸く、レールより一段明るい |
| 右下 | ?（ヘルプとフィードバック） |

### ホーム

- 上に分割ボタン（セグメント）「管理」「✓ 指導科目」。
- 開いたり閉じたりできるカード 2 つ:「最近期限超過」「注目の機能」。
- 見出し「クラス」と、右に文字ボタン「＋ クラスを追加」。
- クラスのカード（幅・高さ 296 前後）: 上の帯（クラスの色と絵。クラス名とセクションを白い文字で）、下に白い面、いちばん下にアイコン 3 つ（採点簿を開く・Google ドライブ フォルダ・⋮ その他のオプション）。

### クラスの中のタブ

- タブ: **ストリーム / 授業 / メンバー / 採点**（高さ 48）。選ばれたタブは青い文字と下に 3px の青い線。
- タブの行の右にアイコン: Google カレンダー・クラスのドライブ フォルダ・クラスの設定（歯車）。
- 新しいものがあるタブ（例: 採点）には青い点が付く。

### ストリーム

- 大きな帯（バナー）: クラスの色と絵に、クラス名とセクション。右上に「✎ カスタマイズ」、右下に ⓘ（クラスの情報）。
- 左の列（幅 196）にカード:「Meet」（⋮・リンクを生成）、「クラスコード」（⋮・コード・全画面表示）、「期限間近」（提出期限の近い課題が無いときは「提出期限の近い課題はありません」と「すべて表示」）。
- 右の列: 「✎ 新しいお知らせ」（薄い青の地の丸いボタン）と「⇄ 再投稿」（文字ボタン）。その下に投稿の行。
  - 課題の投稿: アイコン ＋「〇〇 さんが新しい課題を投稿しました: 題名」＋ 日付 ＋ ⋮。
  - お知らせ: アバター ＋ 名前 ＋ 日付 ＋ 本文 ＋「コメントを追加」。

### 授業と［＋ 作成］

- 左上に主ボタン「**＋ 作成**」（青の塗り）。右に文字ボタン「すべて折りたたむ」。
- ［＋ 作成］のメニュー（各項目にアイコン。線で 3 つに区切る）:
  1. 課題 / テスト付きの課題 / 質問 / 資料 / 投稿を再利用
  2. Gemini Notebook / Gem
  3. トピック
- トピックの見出し（右に折りたたみ ^。下に線）の下に、そのトピックの行が並ぶ。
- 行（高さ 60 前後・線で区切る）: アイコン ＋ 題名 ＋ 右に「投稿日: 4月5日」か「期限: 2020/05/15」＋ ⋮。

### 課題の作成（全画面）

- 上の帯: 左に ×（閉じる）・アイコン・「課題」。右に分割ボタン「**割り当て ▾**」。題名を入れるまで押せない（灰色）。
- 本文（左）: 白いカードを縦に並べる。
  - 「タイトル*」（塗りの入力欄）と「課題の詳細（省略可）」（太字・斜体・下線・箇条書き・書式のクリア）
  - 「学習目標をタグ付け ⓘ」と緑の「New」チップ
  - 「添付」: 丸いアイコンのボタン（ドライブ・YouTube・作成・Read Along・アップロード・リンク・Gemini Notebook・Gem）
- 右の列（幅 364・左に線）: 上から「対象」（クラスの選択）・「割り当て先」（枠の丸いボタン「すべての生徒」）・「点数」（100）・「期限」（期限なし）・「トピック」（トピックなし）・「ルーブリック」（枠の丸いボタン「＋ ルーブリック」）・チェック「盗用（独自性）を確認する」と詳細。

### メンバー

- 見出し「教師」と、右に人＋のアイコン（教師を招待）。下に線。行はアバター ＋ 名前。
- 枠の丸いボタン「保護者のアクセスを有効にする」。
- 見出し「生徒」と招待のアイコン。生徒がいないときは、絵 ＋「このクラスに生徒を追加」＋ 文字ボタン「生徒を招待」。

### 採点（採点簿）

- 上にセグメント「✓ 採点簿」「学習目標」と、緑の「New」チップ。
- 表: 左の列の上に並べ替えの選択（「姓で並べ替え」）、行「クラス平均」、その下に生徒の行（アバター ＋ 名前）。列は課題ごと（「期限なし」＋ 題名のリンク ＋ ⋮）。線で区切る。
- 初めて開くと説明のダイアログが出る（絵・見出し・本文・右下に文字ボタン 2 つ）。

### 課題の詳細と生徒の提出物

タブ「**手順**」「**生徒の提出物**」。

- 手順: アイコン ＋ 題名 ＋ ⋮、「投稿者 • 日付」、線、添付のカード（左に名前と URL、右にアイコン）、「クラスのコメント」と文字ボタン「コメントを追加」。
- 生徒の提出物:
  - 上の行: 分割ボタン「返却 ▾」（生徒を選ぶまで押せない）・メール・「未採点」の選択・右に設定の歯車。
  - 左の列: 「すべての生徒」のチェック、「ステータスで並べ替え」、まとまり（例: 「割り当て済み」）ごとに生徒の行（チェック・アバター・名前・成績の欄）。
  - 右: 題名、大きな数字と説明（「0 提出済み」「4 割り当て済み」）、「提出を受け付けています ⓘ」、絞り込み「すべて」・フォルダ、生徒のカード（名前 ＋ 状態「割り当て済み」）。

### クラスの設定（全画面）

- 上の帯: 左に × と「クラスの設定」、右に「**保存**」（何か変えるまで押せない）。
- 白いカード（幅 752）を縦に並べ、カードごとに大きな見出し:
  - 「クラスの詳細」: クラス名*・クラスの説明・セクション・学年・科目・部屋
  - 「全般」: 小見出し「招待コード」「ストリームと授業」「保護者によるアクセス」「Meet のリンクを管理」
  - 「採点」: 未提出の課題の仮成績・成績の計算・成績のカテゴリ
  - 「学習目標」: クラスの基準セット・学習目標スコアの計算
- 設定の行: 左に名前（と小さい説明）、右に値（「オン ▾」の青い文字）かスイッチ。

### ダイアログ

- 角丸の大きい面（幅 560）。後ろの幕は黒 32%。
- 見出し（22px・太くしない）・本文（14px）・右下に文字ボタン（青）を並べる（例:「後で」「クラスの基準セットの選択」）。
- 中でスイッチ（青）・塗りの入力欄も使う。

## 言葉の一覧

左が Google Classroom の言葉、右がスモウルビーのクラス管理で使う言葉。`.claude/rules/scratch-gui/classroom-ui.md` の「言葉の対応」と [`ui-ux.md`](ui-ux.md) の「言葉の対応表」が正で、この表はそれに合わせている。

### 同じ意味で使う言葉

| Google Classroom | クラス管理 | 補足 |
|---|---|---|
| クラスを作成（＋ のメニュー） | **クラスを作成** | ホームの見出しの横の文字ボタンは「＋ クラスを追加」だが、クラス管理は「クラスを作成」にそろえる |
| ＋ 作成 | **［＋ 作成 ▾］** | 作る操作をまとめるメニュー |
| 課題（［＋ 作成］の中） | **課題** | |
| トピック（［＋ 作成］の中） | **トピック／トピックを追加** | |
| 投稿を再利用 | **課題を再利用** | クラス管理で再利用できるのは課題だけなので「課題を」にする |
| ストリーム / 授業 | **ストリーム / 授業** | クラスの画面のタブ |
| メンバー | **メンバー** | クラス管理では課題の詳細のタブ（下の「いまの画面との差」） |
| 採点 / 採点簿 | **採点** | |
| セクション | **セクション** | |
| アーカイブされたクラス | **アーカイブ済みのクラス** | |
| 返却 | **返却** | |
| 提出済み | **提出済み** | |

### 意味が違うので分ける言葉

| Google Classroom | クラス管理 | 分ける理由 |
|---|---|---|
| クラスコード / 招待コード | **参加コード** | クラス管理のコードは**課題ごと**で、生徒は課題に参加する。クラス（学級）単位のクラスコードとは単位が違う。スモウルビーの正式名称なのでそのまま |
| 期限（提出の期限） | **保存期限** | クラス管理の保存期限は、提出物のデータが自動で消える日。提出の締め切りではない |
| 投稿日 | **授業日** | 並び順に使う授業の日（既定は作成日）。投稿した日とは限らない |
| お知らせ（ストリームへの投稿） | **お知らせ**（お知らせセンター） | クラス管理のお知らせは、運営から先生へ届くもの（タイトルバーのベル）。先生が生徒へ向けて投稿するものではない |
| ルーブリック | **採点の観点** | ルーブリックの「基準」は S/A/B/C のレベルの説明まで含む。名前と説明だけの採点の観点とは意味がずれる |
| 学年 | **年度** | 学年とは別の値。Google Classroom には年度が無いが、クラス管理では残す |
| 手順（課題の詳細のタブ） | **説明**（課題の詳細のタブ） | 中身は課題のページとスタータープロジェクト。行の［課題を開く］が「手順を表示」にあたる |
| 割り当て済み | **参加済み** | 生徒は参加コードで課題に参加する。先生が生徒を割り当てる形ではない |
| 教師 | **先生** | 画面の言葉は「先生」 |

### クラス管理に無いもの・Google Classroom に無いもの

- Google Classroom にだけある: テスト付きの課題・質問・資料・Gemini Notebook・Gem・Meet・カレンダー・ドライブ フォルダ・保護者のアクセス・学習目標・盗用の確認。
- クラス管理にだけある（［＋ 作成 ▾］の中）: レッスン・みんなの課題からさがす・合言葉で取り込み。

## 操作の置き場所のきまり

画面から読み取れたきまり。クラス管理の規約（R1〜R6）と重なるものは、その番号を書く。

| きまり | Google Classroom での形 | クラス管理の規約 |
|---|---|---|
| 作る操作は 1 つにまとめる | ［授業］の［＋ 作成］のメニュー 1 つ | R2 |
| 作る・設定する画面は全画面に切りかえる | 課題の作成・クラスの設定は全画面。左上に ×、右上に確定（割り当て・保存） | R6（確定のボタンが必ず見える） |
| 入れるまで確定は押せない | 「割り当て」は題名を入れるまで、「保存」は何か変えるまで、「返却」は生徒を選ぶまで灰色 | — |
| まれな操作・消す操作は ⋮ の中 | カード・行・トピックの見出し・バナーのカードの ⋮ | R2 |
| 空のときは絵と 1 文と 1 つの操作 | メンバーの生徒が 0 人:「このクラスに生徒を追加」＋「生徒を招待」 | — |
| 新しい機能のしるし | 緑の「New」チップ（学習目標など） | — |
| 新しいものがあるしるし | タブの横の青い点（採点など） | — |

## いまの画面との差（参考）

[`ui-ux.md`](ui-ux.md) のいまのクラス管理の画面と比べて気づいた差。直すかどうかはここでは決めない（決めるのは画面ごとの Issue）。意図して違えているものは、その理由も書く。

| 場所 | Google Classroom | いまのクラス管理 |
|---|---|---|
| 全体の移動 | 左のレール（ホーム・指導科目・アーカイブされたクラス・設定） | サイドバーは無く、パンくず（「クラス一覧 > クラス名 > ストリーム｜授業」） |
| クラスの中のタブ | ストリーム / 授業 / メンバー / 採点 の 4 つ | ストリーム / 授業 の 2 つ。採点はクラス一覧のカードの「採点」から開き、メンバーは課題の詳細のタブ（生徒が参加するのは課題なので） |
| ストリームの左の列 | クラスコード・Meet・期限間近のカード | 置かない（参加コードは課題ごとなので、クラスコードのカードは置かない） |
| ストリームの行 | 投稿者の名前つき「新しい課題を投稿しました」。お知らせを投稿できる | 「課題「〜」を作成しました」などの行だけ。保存期限が近い課題は赤でいちばん上 |
| クラスのカード | 下にアイコン 3 つ（採点簿・ドライブ・⋮） | 「採点」「設定」のボタン。名前の下に要約（課題の数・生徒の数・生成AI） |
| 授業の行の右 | 「投稿日」か「期限」＋ ⋮ | 「授業日」＋ ⋮。押すとその場で開く行 |
| 課題の作成 | 全画面。題名・詳細・添付と、右の列に対象・点数・期限など。右上に「割り当て ▾」 | 課題名だけを聞く作成画面。説明やスターターは作ったあと課題の詳細の「説明」タブで入れる |
| 課題の詳細のタブ | 手順 / 生徒の提出物 | メンバー / 説明 / 進み具合 など |
| 確定のボタンの場所 | 全画面の上の帯の右上（割り当て・保存） | 説明タブの［課題を保存］はタブのすぐ下の右。クラスの設定の［キャンセル / アーカイブ / 保存］は本文の下端に留める |
| 保存のボタン | 何か変えるまで押せない | 変えた行に「未保存」の印を付ける |
| 新しいもののしるし | タブの青い点・緑の「New」チップ | お知らせが未読のとき、タイトルバーのベルに未読数のバッジ、メニューに「!」のバッジ |
| 枠と色 | 白い面と薄い青の地、主の色は青 `#0B57D0`、角丸の大きいボタン | Scratch のモーダルの中に出す（ヘッダーは紫）。主ボタンは共通の主ボタン |
| 小さな画面 | ダイアログ（角丸 28・右下に文字ボタン） | 「クラスを作成」「トピックを追加」は小さな画面（［キャンセル］［作成］／［追加］） |
