## 第1章 `blockBasics` — ネコからにげる簡単なゲーム

**ゲーム設計（本文の「どうやってつくるか考える」）**

1. ネコがマウスのポインターの方向を向く
2. ネコがマウスのポインターのある方向に歩き出す
3. もしネコがマウスのポインターにふれたなら「こんにちは！」と 2 秒間言う

→ 実体は「マウスポインターを追いかけるネコ（オニごっこ）」。ユーザーはマウスでネコから逃げる。

**完成プログラム（ネコ＝スプライト1）**

ブロック（Lv1/Lv2 が組む形）:
```
[🏳 が押されたとき]
 └ ずっと
     ├ [マウスのポインター ▼] へ向ける
     ├ (10) 歩動かす
     └ もし〈[マウスのポインター ▼] に触れた〉なら
          └ (こんにちは!) と (2) 秒言う
```

Ruby（Lv3 / `code` 挿入に使う）:
```ruby
when(:flag_clicked) do
  loop do
    point_towards("_mouse_")
    move(10)
    if touching?("_mouse_")
      say("こんにちは!", 2)
    end
  end
end
```

**Lv1 で変えるパラメータ例**: 台詞 `"こんにちは!"` / 歩数 `10` / 秒数 `2`。

## 第4章 `blockGames` — シューティングゲーム

**ゲーム設計（本文の「シューティングゲームのやり方」）**

1. キーボードの方向キー（上下）で、ネコが上下に移動する
2. スペースキーで、ネコが右に向かってタマを出す（発射）
3. ガイコツはつねに画面右はしで上下に移動する
4. ガイコツにタマが当たったら、ガイコツは消える

3 スプライト構成: **ネコ（スプライト1・自機）** / **タマ（Arrow1）** / **ガイコツ（Skeleton・敵）**。

### ネコ（スプライト1）— 上下移動

Ruby:
```ruby
when(:key_pressed, "up arrow") do
  self.y += 10
end
when(:key_pressed, "down arrow") do
  self.y += -10
end
```
（ブロック: 「[上向き矢印▼] キーが押されたとき → y座標を (10) ずつ変える」／下は `-10`。
y 座標＝上下位置。大きく＝上、`-` で小さく＝下。キーは `w`/`s` でも可。）

### タマ（Arrow1）— 発射して右へ飛び、はしで消える

Ruby:
```ruby
when(:flag_clicked) do
  hide
end
when(:key_pressed, "space") do
  go_to("スプライト 1")
  show
  until touching?("_edge_")
    self.x += 10
  end
  hide
end
```
（ブロック: 旗→「隠す」。スペース→「[スプライト1▼] へ行く」「表示する」「〈[端▼]に触れた〉まで繰り返す（x座標を10ずつ変える）」「隠す」。
`touching?("_edge_")`＝端に触れた。`_edge_`→`_mouse_` でマウス判定にもできる。）

### ガイコツ（Skeleton）— 右はしで上下移動し、タマに当たると消える

事前設定: スプライトの「向き」を 0 度（上向き）にする。

Ruby:
```ruby
when(:flag_clicked) do
  self.rotation_style = "left-right"
  show
  until touching?("Arrow1")
    move(10)
    bounce_if_on_edge
  end
  hide
end
```
（ブロック: 旗→「回転方法を [左右のみ▼] にする」「表示する」「〈[Arrow1▼]に触れた〉まで繰り返す（(10)歩動かす／もし端に着いたら、跳ね返る）」「隠す」。
`bounce_if_on_edge`＝もし端に着いたら跳ね返る。`rotation_style="left-right"` で向きが乱れないようにする。
`touching?("Arrow1")` の `"Arrow1"` はタマのスプライト名。別画像を選んだ場合はその名前にする。）

### 発展（`block-*-advanced`・Lv0 相当で「見せるだけ」）

- タマをたくさん出せるようにする → **クローン**機能を使う（`self` のクローンを作ってタマを増やす）。
  発展は完成コードを動かして見せるに留め、詳細は書籍へ誘導する。
