# ふりがな対応表

Ruby tab のふりがな機能（「ふ」ボタン）で表示されるふりがなの対応表です。

実装: `src/lib/furigana-annotator.js`

---

## 変数

| Ruby | ふりがな |
|------|---------|
| `x = ...`（ローカル変数代入） | `変数x` `紐付けろ` |
| `x`（ローカル変数参照） | `変数x` |
| `@x = ...`（インスタンス変数代入） | `変数x` `紐付けろ` |
| `@x`（インスタンス変数参照） | `変数x` |

## リテラル

| Ruby | ふりがな |
|------|---------|
| `10`, `-5` など整数 | `数値10` |
| `0.7`, `3.14` など浮動小数点数 | `数値0.7` |
| `"hello"` 文字列 | `文字列「hello」` |

## メソッド呼び出し（レシーバなし）

| Ruby | ふりがな |
|------|---------|
| `puts` / `print` | `表示しろ` |
| `gets` | `入力文字列を取得` |

## メソッド呼び出し（レシーバあり）

| Ruby | ふりがな |
|------|---------|
| `.to_i` | `整数化` |
| `.to_s` | `文字列化` |

## 算術演算子

| Ruby | ふりがな | 備考 |
|------|---------|------|
| `+` | `足す` | レシーバが数値の場合 |
| `+` | `連結` | レシーバが文字列の場合 |
| `-` | `引く` | |
| `*` | `掛ける` | |
| `/` | `割る` | |
| `%` | `余り` | |

## 比較演算子

| Ruby | ふりがな |
|------|---------|
| `<=` | `以下` |
| `>=` | `以上` |
| `<` | `小さい` |
| `>` | `大きい` |
| `==` | `等しい` |
| `!=` | `等しくない` |

## 論理演算子

| Ruby | ふりがな |
|------|---------|
| `&&` | `かつ` |
| `\|\|` | `または` |
| `!` | `ではない` |

## 制御構造

| Ruby | ふりがな | 備考 |
|------|---------|------|
| `if` | `もしも` | |
| `elsif` | `そうではなく` | |
| `else` | `そうでなければ` | |
| `end`（if / case） | `分岐終了` | |
| `while` | `繰り返す` | |
| `end`（while / do ブロック） | `ブロック終了` | |
| `def` | `メソッド作成` | |
| `end`（def） | `作成終了` | |
| `case` | `状態分岐` | |
| `when` | `のとき` | |
