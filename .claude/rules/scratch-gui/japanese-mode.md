# 日本語モード（DNCL モード）の方針

`packages/scratch-gui/src/lib/dncl/`、`src/containers/ruby-tab/dncl-*.js`、`src/lib/genai-dncl-prompt.js`、
`docs/dncl/`、`docs/smalruby-dncl-spec.ja.md` を変えるときは、**先に `docs/dncl/policy.md` を読む**。

要点（正準は `docs/dncl/policy.md`）:

- 対応するのは、共通テスト「情報I」の**共通テスト用プログラム表記**。まとまった仕様書は無く、
  問題文の補足で読めるようにした書き方。試験で問われるのは読み解く力（穴埋め・出力の予想）で、
  0 から書く力ではない。
- 大学入試センターの「DNCL の説明」は**情報関係基礎**のためのもので、情報I とは別物。
  受験者が DNCL を知っている前提の問題は出ない。
- 日本語モードは**プログラムを読む力をつけるための機能**。
- 文法の決め方: 複数の例題で共通の書き方を探す → 揺れは DNCL（か DNCL に近いもの）を選ぶ →
  DNCL に無いものは複数の例題から、DNCL か Ruby に近いものを選ぶ → 理由を Issue / PR に残す。
- 目指す形: 文法を設定（チェックボックス）で選べ、設定はプログラムの冒頭に説明文として書かれ、
  よくある設定のパターンが用意され、プログラムは設定に従った文法で表される。
- 「DNCL」と書くときは、情報関係基礎の DNCL か、情報I の共通テスト用プログラム表記かを区別する。
