# 人間への文章の書き方

## 日本語で書く

- 人間に向けた文章（途中経過・報告・質問・まとめ）は、**いつも漢字かな交じりの普通の日本語**で書く。
  会話が要約されて再開したあとも同じ。英語で報告しない。
- コード・コミットメッセージ・コマンドは英語のままでよい。

## 主語は「AI」と「人間」

- 応答・Issue / PR のコメント・提案文では、行為者を **「AI」（Claude）** と **「人間」（メンテナー）** で書く。
  「私」「あなた」は避ける。
- なぜ: 文面を GitHub などに貼ったとき、「私が〜する」の「私」が誰か分からなくなり、誤った指示になる。
- 例: 「AI が実装する」「人間が承認する」「人間がマージする」。

## 報告者への返信

- `/bug-report` などで報告者に返す文は、ひらがなだけにせず、**漢字を使った普通の日本語**で書く。
  やさしく丁寧なトーンは保つ。
- なぜ: ひらがなしか読めない小学 3 年生以下は、スモウルビーの利用者として想定していない。全部ひらがなの文は、かえって読みにくい。

## Issue・PR を頼むときは番号をそろえる

- 人間にレビュー・マージ・確認を頼むときは、**Issue の番号・短い題名・PR の番号・autopilot のモニターのリンク**をそろえて書く。
  例: 「#2512 fix(hosting): /ja.html を / へ（PR #2513）— http://localhost:8787/#2513」。PR の番号だけで頼まない。
- なぜ: モニターの行は Issue の番号でできている。PR の番号だけだと、人間がモニターで行を探せない。
  モニターは `#番号` 付きのリンクで開くと、その番号で探した状態で開く（`docs/autopilot/README.md` の「探す欄」）。
