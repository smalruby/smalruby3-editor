# UI/UX レビュー コンテキスト

## 目的

定義されたペルソナの視点で、機能の使いやすさを評価する。初心者が迷わず操作でき、かつ経験者に余計な手間をかけさせない UI/UX になっているかを確認する。

## 基本原則

### 初心者にとって

- **次のアクションが明確**: 画面を見ただけで何をすべきかわかる
- **十分な情報表示**: ヒント、説明文、プレースホルダーが適切に配置されている
- **エラーからの回復が容易**: エラーメッセージが具体的で、次のアクションが提示される
- **用語が理解可能**: 専門用語を避けるか、説明が添えられている

### 経験者にとって

- **冗長な説明が邪魔にならない**: 常時表示のヒントがメインコンテンツを圧迫しない
- **余計な確認ダイアログがない**: 安全な操作に不要な確認を求めない
- **ショートカットがある**: 繰り返し操作に素早いパスがある（例: 参加リンク）
- **状態が一目でわかる**: ダッシュボード等で全体像を把握できる

## レビュー手順

### Step 1: ペルソナごとのウォークスルー

`docs/<feature>/` のペルソナ定義を読み込み、各ペルソナで以下を実施する:

1. **初回体験フロー**: 機能を初めて使う想定で最初から最後まで操作する
2. **2回目以降のフロー**: セッション復帰、再操作の体験を確認する
3. **各画面で「5秒ルール」チェック**: 画面を見て5秒以内に次のアクションがわかるか

### Step 2: Playwright MCP でスクリーンショットベースの評価

各画面をスクリーンショットで記録し、以下の観点で評価する:

**情報の十分さ:**
- [ ] 各画面に見出しがあり、現在の状況がわかる
- [ ] 入力フィールドにラベルとプレースホルダーがある
- [ ] ボタンのテキストが操作内容を正確に表している
- [ ] エラーメッセージが具体的で、対処方法が含まれている
- [ ] 初回ユーザー向けのヒントやチュートリアルがある

**情報の邪魔にならなさ:**
- [ ] ヒントやチュートリアルが、メインコンテンツのスペースを過度に奪っていない
- [ ] 閉じたチュートリアルが再度表示されない
- [ ] 確認ダイアログが本当に必要な場面のみに使われている
- [ ] ローディング表示が操作を長時間ブロックしない
- [ ] 成功メッセージの表示が自然に消える（または操作を妨げない）

**視覚的な一貫性:**
- [ ] ボタンの色使いが一貫している（青=主要アクション、赤=破壊的操作）
- [ ] フォントサイズと間隔が統一されている
- [ ] アイコンと文字の組み合わせが直感的
- [ ] 状態変化（着席/提出/返却等）が色やアイコンで区別できる

**アクセシビリティ:**
- [ ] ボタンやリンクが十分なサイズ（44px 以上のタッチターゲット）
- [ ] コントラスト比が十分（WCAG AA レベル）
- [ ] フォーカス順序が論理的

### Step 3: フロー全体の評価

各ペルソナの典型的なフローを通して、以下を評価する:

**オンボーディング:**
- 初めて機能を使うユーザーが、外部のマニュアルなしに操作を完了できるか
- チュートリアルやヒントが自然なタイミングで表示されるか

**エラーリカバリ:**
- エラーが発生した場合、ユーザーが自力で回復できるか
- 「戻る」や「やり直す」が常に利用可能か

**状態の永続化:**
- ブラウザを閉じて再度開いたとき、適切に復帰するか
- セッション切れ時に、わかりやすいメッセージと復帰手段があるか

**フィードバック:**
- 操作後に適切なフィードバック（成功/失敗）があるか
- 処理中であることがユーザーに伝わるか（ローディング表示）

### Step 4: レスポンシブ・環境差の確認

- タブレット（1024x768）での表示を確認
- ブラウザのデフォルトフォントサイズが大きい場合のレイアウト崩れ

Playwright MCP でのリサイズ:
```javascript
await page.setViewportSize({ width: 1024, height: 768 });
```

## 発見事項の記録

各発見事項を以下の形式で記録する:

```
### [重要度] <タイトル>
- **ペルソナ**: <影響を受けるペルソナ>
- **場所**: <画面名>
- **問題**: <何が問題か、ユーザーがどう困るか>
- **改善案**: <具体的な改善提案>
- **スクリーンショット**: (あれば)
```

## 判定基準

| 重要度 | 基準 |
|--------|------|
| Critical | ユーザーがフローを完了できない。次のアクションが全くわからない |
| Warning | ユーザーが迷うが最終的には操作できる。UX が不自然 |
| Info | 改善すればより良くなる。ベストプラクティスからの逸脱 |
