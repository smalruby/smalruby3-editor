# スモウルビー標準課題（assignments/）

クラス管理で使う「標準課題」の成果物です。エディタと一緒に `https://smalruby.app/assignments/` で公開します。
説明・決まりごとは [`docs/standard-assignments/README.md`](../docs/standard-assignments/README.md) を見てください。

- ライセンス: CC0 1.0（[`LICENSE`](LICENSE)）。リポジトリのほかの部分のライセンスとは別です。
- ここに置くのは成果物（課題の説明の JSON・PDF・sb3）だけです。原本と生成スクリプトはリポジトリの外にあります。
- `<課題のID>/<版>/` は一度置いたら変えません。直すときは新しい版のディレクトリを足し、`<課題のID>/` （最新）をその版と同じ中身にします。
