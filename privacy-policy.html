プライバシーポリシー

制定日：2025年3月3日（最終改定：2026年3月5日）
運営者：NPO法人Rubyプログラミング少年団

NPO法人Rubyプログラミング少年団（以下「当法人」）は、スモウルビー（https://smalruby.app、以下「本サービス」）の運営にあたり、ユーザーのプライバシーを尊重し、個人情報の適切な保護に努めます。

1. 基本方針

本サービスは、ユーザー登録やログインを必要としない無料のビジュアルプログラミング環境です。当法人は、サービス提供に必要な範囲を超えてユーザーの個人情報を収集・利用しません。

2. 収集する情報

2.1 Google OAuth 認証について

本サービスでは、任意でGoogleドライブとの連携機能をご利用いただけます。この機能を使用する場合のみ、GoogleのOAuth 2.0認証を使用します。

  • 認証時に取得するのはアクセストークンのみです。お名前・メールアドレス・プロフィール画像等のプロフィール情報は一切取得しません。
  • アクセストークンはブラウザのメモリ上にのみ保持されます。当法人のサーバーに送信・保存されることはありません。
  • Googleドライブ連携を使用しない場合、Google認証は行われません。

2.2 Google API の使用について

本サービスは以下の Google API を使用します。

  • Google Drive API（drive.file スコープ）
    ユーザーが Google ピッカーで明示的に選択したファイルの読み取り、および Google ドライブへのファイルのアップロード・更新のために使用します。ユーザーが選択していないファイルやフォルダにはアクセスしません。

Google API から取得した情報の使用は、Google API サービスのユーザーデータポリシーに準拠します。これには、限定的な使用の要件が含まれます。

2.3 AI コード生成支援（ルビティー）について

本サービスでは、AI による Ruby コード生成支援機能「ルビティー」をご利用いただけます。この機能は、当法人が運営する中継サービス（smalruby-rubytee-relay）を経由して Anthropic 社の Claude API に接続します。Google アカウントへのログインは不要です。

  • この機能をご利用の場合、入力されたコードの文脈情報が当法人の中継サービス（AWS Lambda）を経由して Anthropic 社に送信されます。
  • 中継サービスはリクエストを転送するのみで、コードの内容を保存しません。ただし、安全性の監視を目的として、匿名化されたリクエストログを一定期間保持します。
  • Anthropic 社の利用規約: Anthropic Usage Policy
  • Anthropic 社のプライバシーポリシー: Anthropic Privacy Policy

2.4 アクセス解析（Google タグマネージャー / Google Analytics）

本サービスでは、サービスの改善を目的として、Google タグマネージャー（GTM）を通じた Google Analytics 4（GA4）によるアクセス解析を実施しています。

収集される情報の例：

  • ページビュー数・滞在時間等のアクセス情報
  • ご利用の機能・拡張機能の使用状況
  • ブラウザの種類・OS・画面サイズ等の環境情報
  • IPアドレス（Google のサーバーで処理され、当法人は直接取得しません）

これらの情報は統計的なサービス改善のみに使用し、個人を特定する目的では使用しません。広告への利用は一切行いません。 Google Analytics のデータ収集を無効にする場合は、Google Analytics オプトアウトアドオンをご利用ください。

3. 情報の利用目的

収集した情報は以下の目的で使用します。

  • 本サービスの正常な提供・運営
  • ユーザーエクスペリエンスの向上
  • 機能の改善・新機能の開発
  • 利用状況の把握（広告目的を除く）

4. 情報の第三者提供

当法人は、法令に基づく場合を除き、収集した情報を第三者に提供・販売しません。

5. 利用する外部サービス

本サービスでは以下の外部サービスを利用しています。各サービスのプライバシーポリシーについては、各社のウェブサイトをご参照ください。

  • Google プライバシーポリシー（Google Drive、Google Analytics、Google タグマネージャー）
  • Anthropic Usage Policy（AI コード生成支援機能「ルビティー」）
  • Anthropic Privacy Policy（AI コード生成支援機能「ルビティー」）

6. Cookie について

本サービスでは、Google Analytics による利用状況の分析のため Cookie を使用することがあります。ブラウザの設定により Cookie を無効にすることができますが、一部機能が正常に動作しない場合があります。
